# 5/ Business model

La plateforme adopte un modèle hybride pour garantir la scalabilité et l'accessibilité.

## 1. Sources de revenus
- **Commission sur transaction** : 10% de frais prélevés sur chaque course payée par le commerçant.
- **Abonnement "Premium" pour Livreurs** : 2 000 XAF / mois pour un accès prioritaire aux missions les plus rentables.
- **Publicité locale** : Possibilité pour les grossistes d'afficher des promotions aux commerçants.

## 2. Flux Mobile Money
1. **Dépôt (Escrow)** : Le commerçant paie le montant de la course dès l'acceptation par un livreur. L'argent est stocké sur un compte de séquestre de la plateforme.
2. **Validation** : Une fois la livraison confirmée par le commerçant (ou via code PIN reçu par le client final), les fonds sont débloqués.
3. **Versement** : Le livreur peut demander le transfert de son solde vers son propre compte Mobile Money (Payout API MTN/Orange).

## 3. Avantages du modèle
- **Sécurité** : Le livreur est certain d'être payé s'il effectue sa mission.
- **Flexibilité** : Pas de frais fixes pour les petits commerçants.
- **Transparence** : Historique complet exportable pour la comptabilité.
